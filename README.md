# فرح 🎊
تطبيق حجز قاعات الأفراح في ليبيا

## عن التطبيق
تطبيق يتيح للمستخدمين البحث عن قاعات الأفراح وحجزها بسهولة،
ويوفر لأصحاب القاعات لوحة تحكم لإدارة الحجوزات.

## المميزات
- 🔍 البحث عن القاعات وتصفيتها
- 📅 حجز القاعات واختيار التاريخ
- 💳 نظام دفع ومحفظة إلكترونية
- 🔔 إشعارات الحجز والتأكيد
- 👤 لوحة تحكم لأصحاب القاعات
- 🌙 دعم اللغة العربية الكامل

## التقنيات المستخدمة
- **Flutter** — واجهة المستخدم
- **Supabase** — قاعدة البيانات والمصادقة
- **Firebase** — الإشعارات والويب
- **Riverpod** — إدارة الحالة

## ملاحظة تقنية
المشروع بدأ بـ Firebase كقاعدة بيانات رئيسية،
ثم تم التحول إلى Supabase مع الإبقاء على Firebase للإشعارات فقط.

## كيفية التشغيل
1. انسخ ملف `.env.example` وسمّه `.env`
2. أضف القيم الحقيقية للـ keys
3. شغّل الأوامر التالية:
```bash
flutter pub get
flutter run
